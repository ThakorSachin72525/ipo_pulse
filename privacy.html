IPO Pulse

Privacy Policy

Last updated: October 8, 2026

This policy explains how IPO Pulse handles information when you use the application and when you authorize its Gmail report-sending feature.

What IPO Pulse is

IPO Pulse is an Indian IPO tracking and analysis application. It stores IPO market information, GMP observations, estimates, and listing outcomes in its database to display dashboards and prepare daily reports.

Google and Gmail information

If the Gmail report feature is authorized, IPO Pulse uses Google OAuth credentials to obtain a temporary access token and send the daily IPO Pulse report through the Gmail API. The report is sent to the recipients configured by the project owner.

The current application code uses Gmail to send messages. It does not search, read, or analyze inbox messages, contacts, or attachments, and it does not retrieve Gmail profile information. The OAuth scope configured for this project is https://mail.google.com/, which is a broad Gmail permission. Google may therefore describe the authorization as allowing broad access to Gmail, even though the application's implemented use is the report-sending function.

How Google user data is used

Google authorization is used only to support the intended IPO Pulse daily email report functionality. The application uses the authorized Gmail account to deliver a report assembled from IPO Pulse market data to the configured recipient addresses.

Storage and security

OAuth client credentials and the refresh token are stored as confidential GitHub Actions secrets. A short-lived access token is used by the workflow to call Google and is not intentionally saved by IPO Pulse. The application does not store Gmail inbox content or attachments. Gmail may retain sent messages in the authorized account according to that account's normal settings.

IPO market data used by the dashboard and report is stored in Supabase. GitHub Actions runs the scheduled application and handles its configured secrets. No credentials should be placed in the public website or source code.

Sharing

IPO Pulse does not sell Google user data or use it for advertising. Information is shared only as needed to provide the requested functionality: Google processes the email for delivery, GitHub Actions runs the application, and Supabase stores IPO Pulse market data. IPO Pulse does not share Google user data with other third parties for their own purposes.

Retention and deletion

GitHub Actions secrets are retained until the project owner changes or deletes them. Temporary access tokens are used during a workflow run and are not intentionally retained by the application. Sent reports may remain in Gmail until deleted from that account. IPO Pulse market data remains in Supabase until the project owner removes it. The project does not maintain a separate archive of Gmail messages.

Revoking Google access

You can revoke the application's Google account access from your Google Account third-party connections. The project owner can also remove or replace the OAuth secrets in the repository's GitHub Actions settings. Revoking access prevents future report sends until authorization is restored.
